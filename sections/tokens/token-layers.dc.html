Capas de tokens

Tres capas: primitivo (valor), semántico (función), componente (propiedad).

De token a componente

Cómo llega un color al estilo de un componente: el valor (primitivo) se asigna a una función (semántico) y la función se aplica a una propiedad del componente.

Primitivo
brand.600
→
Semántico
acción primaria
action.primary
→
Componente
Hacer la foto
button.primary.bg

Los componentes usan roles semánticos. Nunca primitivos ni valores hex.
