Form-Select

Elige un único valor de una lista cerrada de opciones. Select nativo: la lista desplegada es la del sistema. Sustituye a ChoiceList (2026-10-15).

components/Select.js · nuevo (decisión del owner, 2026-10-15)

Uso

Sin valor inicial se muestra «Selecciona una opción», que no se puede elegir. Las opciones admiten grupos (valor::Texto::Grupo).

Cuándo pasar a otro control

Para escribir y filtrar una lista larga: patrón 8.2 Autocompletado (escribir filtra; solo una opción válida confirma el valor). Para varios valores: patrón 8.3 Selección múltiple. Para cambiar de vista: 7.7 Nav-SegmentedControl.
