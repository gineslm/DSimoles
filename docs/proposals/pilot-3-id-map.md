# ID migration map (pilot 3, F10)

On 2026-10-09 all IDs, folders and suggested paths moved from Spanish to English slugs, in one controlled migration while only one page existed. IDs are stable from now on and are never reused. Section folders and asset folders follow the category ID: `sections/<category>/` and `assets/<category>/<subsection>/`.

Claude Design: your copy of `data/project.json` and `sections/` uses the old IDs. Synchronize before touching anything; do not copy old keys back.
