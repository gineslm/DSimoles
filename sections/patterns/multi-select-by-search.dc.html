Selección múltiple por búsquedas sucesivas

Elegir varios valores de una lista larga, uno por búsqueda, revisarlos como chips y confirmar el conjunto con un botón.

Problema y cuándo usarlo

Para varios valores de una lista larga. Con pocas opciones visibles, la solución sería una casilla por opción, fuera de esta iteración: el catálogo no tiene checkbox.

Componentes que combina

  • El patrón 8.2 Autocompletado para cada búsqueda
  • 7.3 Vis-Chip eliminable para cada valor elegido
  • 7.4 Act-Button «Confirmar» para el conjunto

Composición

Composición estática: la búsqueda funciona como en 8.2.

Comportamiento

  1. Cada elección se añade como chip debajo del campo; el campo se vacía para la siguiente búsqueda.
  2. Las opciones ya elegidas no vuelven a aparecer en los resultados.
  3. La x de un chip lo quita. El foco pasa al chip siguiente; si no hay, al anterior; si no queda ninguno, al campo.
  4. El conjunto se confirma con el botón, no al elegir cada valor.

Estados y errores

Estado
Qué se muestra
Obligatorio sin selección
Error en Form-Field
Máximo alcanzado
El campo se desactiva; ayuda «Máximo N»
Sin cambios
«Confirmar» desactivado

Accesibilidad y móvil

  • Los chips forman una lista con nombre («Seleccionados, N»).
  • Añadir y quitar se anuncian con un status («Inglés añadido», «Inglés quitado»).
  • En móvil, los chips pasan a la línea siguiente y «Confirmar» se fija al pie.

Criterios de aceptación

  1. El conjunto solo se guarda al confirmar.
  2. El foco nunca se pierde al quitar un chip.
  3. Añadir y quitar se anuncian.
