Formato de tokens

Decisión para la futura implementación del design system, fuera de este repositorio: aquí no se genera ningún archivo de tokens. Formato W3C Design Tokens Community Group (DTCG): JSON con $value y $type; los tokens semánticos referencian a los primitivos con llaves.

{
  "color": {
    "brand": { "600": { "$type": "color", "$value": "#00698C" } },
    "action": {
      "primary": { "$type": "color", "$value": "{color.brand.600}" }
    }
  }
}
