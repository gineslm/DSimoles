Autocompletado y selección única

Elegir un valor de una lista larga escribiendo para filtrar. Solo la elección de una opción válida confirma el valor.

Problema y cuándo usarlo

Para listas largas (más de unas 15–20 opciones) o cuando el usuario conoce el nombre. Con menos opciones, 7.14 Form-Select nativo. Para texto libre, 7.12 Form-TextField.

Componentes que combina

  • 7.10 Form-Field (etiqueta, ayuda, error)
  • Entrada de texto con el aspecto de Form-TextField
  • Lista de resultados (listbox): se crea dentro de este patrón y solo pasa al catálogo si se reutiliza
  • 7.4 Act-Button clear, solo icono, para limpiar el valor
  • 7.17 Fb-Spinner y 7.20 Fb-InlineAlert para la carga y los errores

Comportamiento

  1. Escribir filtra: desde 1 carácter si la lista es local; desde 2–3 si se consulta un servicio.
  2. Flechas arriba y abajo recorren los resultados; Enter elige; Esc cierra la lista.
  3. Solo una opción válida confirma el valor. Si el usuario sale del campo sin elegir, el texto se descarta y vuelve el valor anterior. No se admite texto libre por defecto.
  4. El valor elegido se muestra en el campo con un botón para limpiarlo.

Estados y errores

Estado
Qué se muestra
Cargando
Fb-Spinner con label en la lista
Sin resultados
«Sin resultados para "texto"»
Error del servicio
Fb-InlineAlert con «Reintentar»
Obligatorio vacío
Error en Form-Field

Accesibilidad y móvil

  • Patrón combobox de ARIA: role="combobox", aria-expanded, aria-controls y aria-activedescendant; lista con role="listbox" y opciones con role="option".
  • El número de resultados se anuncia con un status («12 resultados»).
  • En móvil, la lista ocupa el ancho del campo y el teclado no la tapa; en pantallas muy pequeñas puede abrirse a pantalla completa con un campo de búsqueda.

Criterios de aceptación

  1. No confirma texto libre.
  2. Se usa entero con teclado.
  3. Anuncia los resultados y el estado vacío.
  4. Al salir sin elegir, recupera el valor anterior.

Ejemplo genérico

«Municipio» entre unas 8.000 opciones: escribir «Sego» muestra Segovia y Segorbe; elegir Segovia la confirma.
