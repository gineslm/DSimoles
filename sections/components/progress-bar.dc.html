Fb-ProgressBar

Muestra el avance cuantificable de una operación, de 0 a 100. Entrada propia desde el 2026-10-15 (antes dentro de ProcessSteps).

components/ProgressBar.js

Uso

Sin modo indeterminado: si la duración no se conoce, 7.17 Fb-Spinner. Si el proceso tiene pasos con nombre, 7.19 Fb-ProcessSteps, que la incluye.

Ficha

Campo
Definición
Anatomía
Pista · relleno · valor visible opcional («64 %»).
Tonos
default (brand.primary) · error (status.error.fill), para una operación fallida.
Tokens
size.progress, border.subtle, brand.primary, status.error.fill, radius.pill, type.small
API
value 0–100 · label (obligatorio) · show-value · tone error
