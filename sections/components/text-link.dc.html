Nav-TextLink

Navega a una página, una sección o un recurso; siempre con destino.

components/TextLink.js · HF: «Ver el análisis ›» en 2 Entidad - Accion (detalle)

Contrato revisado (auditoría, 2026-10-15). href obligatorio: se retira el modo botón (una acción sin destino es un Act-Button clear). Sin icono por defecto; icon="chevron_right" solo para abrir un detalle. Externo: siempre open_in_new y aviso oculto. Los enlaces dentro de texto corrido usan el estilo base de a, no TextLink.

Uso

Variantes

interno
externo

Externo: abre la URL en otra ventana. El icono open_in_new sustituye al chevron y el lector de pantalla oye «(se abre en otra ventana)» tras la etiqueta. La URL del ejemplo es ficticia.

Definición
Anatomía
Etiqueta condensada en mayúsculas · chevron final (open_in_new si es externo) · en externo, texto oculto «(se abre en otra ventana)».
Estados
default, hover (subrayado), pressed y focus.
Accesibilidad
<a href> si navega, <button> si no hay URL. Externo: <a target="_blank" rel="noopener noreferrer"> con aviso oculto. Va fuera de texto corrido, así que el color no es la única señal. Área táctil de 44 px.
Tokens
link.default / .hover / .pressed, type.ui, type.ui.tracking, size.icon.xs.
API
label · href · icon (chevron_right por defecto, none para quitarlo) · external (requiere href; fija el icono open_in_new) · on-click.
